# Illaendi Project Instructions

## Scope

- These instructions apply only to the Illaendi project (말의 전장) in `C:\JP_DF`. Do not apply them as defaults for other projects.

## AI Communication Language

- AI-to-AI task instructions, development prompts, reviews, progress reports, and handoffs may use any mutually understood language or format that enables fast, accurate communication. Korean is not required.
- Choose the most efficient expression for the recipient and task, including English, Korean, mixed languages, code, or JSON. Avoid unnecessary translation and repeating the same content in multiple languages.
- Be concise while preserving the objective, target, authorized scope, current status, verification evidence, and unfinished work as needed. Compression must not omit meaning or important conditions.
- Use formal Korean by default for explanations and final replies addressed directly to the user. Follow the user's instructions when they request or permit another language.
