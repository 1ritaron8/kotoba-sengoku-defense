### 전장의 정체성과 플레이 흐름

1번은1560년 마루네의 작은 전방 요새에서 벌어지는 **첫 출전·철수 엄호**입니다. 기존 `basic-forest` ID, 서사, 실제 궁병/창병 해금, 비용·사거리·이동·웨이브·시간제 승패·거점 내구도·학습 내용을 유지합니다. 실제 역사에서는 요새가 함락됐고, 게임의 성공은 허구 인물 하루노부 부대의 철수 엄호입니다. 거점이 버틴 게임 결과를 역사적 요새 생존으로 설명하지 않습니다.

상부 HUD와 하부 카드 영역을 제외한 전장 안에서 **왼쪽 아래 진지 → 중앙 문앞 저지 공간 → 오른쪽 위 적 접근**이 한눈에 이어지게 만듭니다. 적은 현재 단일 전진 경로로 접근합니다. 중앙 저지 공간에서 진지 정문으로 이어지는 길은 실제 적 경로입니다. 최신 사용자 지시에 따라 시각적 퇴로는 중앙 길에서 떨어진 흔적이 아니라 **진지 안쪽 → 열린 후방 목책 통로 → 왼쪽 후방 숲**으로 연속 연결합니다. 퇴로에 새로운 적 출현·피난민·호송·이동 목표·탈출 카운터를 추가하지 않습니다. 현대 지도상의 동서남북과 화면 방향은 구분합니다.

```text
  배경 구릉·수림                         적 접근(오른쪽 위)
                                               ↙
                                   중앙 저지 공간
                                  ↙       양측 사격 자리
              낮은 흙·목책 진지의 문
  후방 숲 ← 열린 후방 통로 ← 작은 주둔 진지(왼쪽 아래)
  ───────────────────────────────────
                  기존 카드 영역
```

카메라는 사용자 TD 예시의 경사 전술 구도와 가까운 교전 크기를 따릅니다. 문 정면·흙둑 측면·병사 전신을 함께 보여 주고, 요새 뒤편을 잘라내거나 상부 숲·건물이 접근로를 덮지 않게 합니다. 수평선 없는 경사 시점으로 화면을 채우며,45도는 첫 검토값일 뿐 고정 승인각이 아닙니다. 버려진58도 구도나 옛 좌표를 되살리지 않습니다. 실제 두 해상도에서 배치·사격선·병과·후리가나를 보고 최종 프레이밍을 정합니다.

후속 UX 직접 사용자 지시는 **매끈하지만 필요한 요소는 갖춘 게임 화면**, **더 가까운 교전 구도**, **실제로 배치한 아군만 표시**입니다. 이를 앞선 사극 재질 선호보다 구체적인 최신 표현 기준으로 적용합니다. 풍화 목재·갑옷·흙의 재질 차이는 유지하되, 과한 고해상도 미세 노이즈·큰 진흙 덩어리·화면 전역의 작은 소품은 줄입니다. 구조·높이·사용 흔적으로 디테일을 전달하고, 가까운 전투 영역 주변에 소품을 모읍니다. 빈 공간을 채우기 위한 장식 병사·망루 승무원·푸른 아군 NPC·배치하지 않은 유령 모델을 넣지 않습니다. 참고 그림의 아군4명·다수 적은 미술 설명일 뿐 실제 초기 인원·생산·스폰을 고정하는 데이터가 아닙니다.

현재 미술 비교 캡처의 임시 `stage.id=vis01-tactical-candidate-v2`는 정식 `basic-forest`와 다른 기본 시각 프로필을 사용하고, 기존 1번 적 체력 보정 조건도 충족하지 않습니다. 따라서 해당 캡처를 정식 1번의 수치·전신 통과 증거로 사용하지 않습니다. 다음 정식 조건의 격리 검증은 `id=basic-forest`, `stageNumber=1`을 Game과 Troops에 일치시켜 적용하고, 후보 식별자·새 지형·격리 계정·미등록 상태는 유지합니다. 학습 연결을 포함하는 Main 검증은 기존 서사와 문항 메타데이터, 실제 새 학습 표식이 준비된 뒤 진행합니다. 임시 ID만 바꾸거나 기본 학습 하나를 불러온 것으로 전체 브리핑·학습·저장·재시도 연결이 완료됐다고 보고하지 않습니다.

학습 표식의 표시·선택 위치와 지원 주문의 실제 출진 위치도 구분합니다. FUN의 현재 코드 검토에서 지원 요청은 문항별 `learningSupportAnchors`를 우선 사용하고, 누락되면 기존 기본 중심 좌표로 떨어질 수 있음을 확인했습니다. 새 제작에서는 실제 문항별 요청 앵커를 명시하고, 누락된 앵커의 기본 중심 좌표로 성공한 것을 공간 연결 통과로 보고하지 않습니다. 현재 지원은 앵커에 가까운 기존 경로를 선택한 뒤 안전한 기지에서 출진하는 계약입니다. 숲·산·물길 표식을 눌렀다고 그 지형 위에 병사가 바로 나타난다고 설명하거나, 물 위 소환·새 지원 경로·추가 보상 체계를 만들지 않습니다. 검증은 표시한 표식, 요청 앵커, 선택된 경로와 실제 출진 기지를 각각 확인합니다.

- 첫 레벨 궁병의 기준 사거리는 정규화 좌표 거리0.205입니다. 양측 사격 자리는 주 중앙 교전점과 움직이는 적을 이 범위 안에 두고, 안쪽 보조 자리는 문 주변을 맡습니다. 보조 자리가 접근로 전체까지 덮는다고 가정하지 않습니다. 판정은 실제 세계 X/Z를 `simulationBounds`로 변환한 거리이며, 화면상의 가까움이나 세계 Y가 아닙니다.
- 사격 자리마다 실제 모집 가능한 위치를 확보합니다. 현재 궁병 배치는 길과 거리0.022 이상, 지면 배치 여유0.012, 기존 최소 배치 간격0.0521 조건을 사용합니다. 원 중심만 검사하지 않고 실제 허용 위치와 유료 배치 결과를 확인합니다. 원형 자리 전체가 같은 교전점을 덮도록 보수적으로 설계할 경우 `중심 거리 + 자리 반경 <= 0.205`가 충분조건입니다. 실제 허용 영역이 다르면 그 위치별 거리와 배우의 현재 사거리를 측정합니다.
- 창병의 탐색 범위0.145와 실제 기본 근접 타격 거리0.041은 다릅니다. 창병이 발견만 하고 닿지 못하는 배치를 피합니다. 기존 저지 한도2를 유지하며, 좁은 문에 적 전체가 무한히 걸리는 장면에 의존하지 않습니다.
- 플랫폼의 실제 높이와 게임의 `unit.elevation`은 구분합니다. 후자는 기존 사거리 배율에 영향을 주므로, 새 지형의 Y값을 그대로 전달하지 않습니다. 먼저 기본 사거리로 주 저지 공간을 성립시키고, 새 고지 보너스를 만들어 문제를 가리지 않습니다.
- 현재 궁병은 지형 Y를 사용하는 물리 사격선 검사를 하지 않습니다. 목책·둑·수관은 의도한 사격선을 비켜 배치하고, 화면에 가려진 발사가 실제 지형 관통 검사까지 통과했다고 주장하지 않습니다.
- 적은 경로 시작에서 끝으로, 창병은 기지 쪽에서 역방향으로 전진합니다. 경로 종점·기지·주 목표를 해자 가장자리가 아닌 내부의 마른 보행 지면에 맞춥니다. 문·꺾임·연결부는 실제 병사 폭과 기존 대열의 점유·통행 검사를 통과해야 합니다.
- 현재 행군 시작점은 경로 끝에서 정규화 거리0.018만큼 안쪽이며, 첫0.030 구간에서 대열의 측면 편차가 최대±0.009까지 생깁니다. 기존 전신 통행 여유0.008과 함께 실제 측면 경로를 검사합니다. 좌우 대칭 직선 구간의 보수적 기능 여유는 반폭0.017보다 크게 잡되, 이는 실제 몸·발·활·창·말 전체가 통과하는 최종 폭 판정이 아닙니다. 종점·파생 시작점·첫 보폭이 같은 마른 지면에 연결되어야 하며, 대열 편차를 억제하거나 가짜 지면으로 통과시키지 않습니다.
- 기본 창병 생산2.275초와 집결·이동, 궁병 생산2.1초와 배치·공격 준비를 포함해 첫 교전까지의 시간을 확인합니다. 궁병1명+창병1명의 기본 비용125를 실제 시작 자금과 비교하며, 재정·웨이브·시간제 승리 값을 임의로 바꾸지 않습니다.

## Common UI and gameplay boundary

The retained interaction state sheet concerns drag preview, valid/invalid feedback, accepted orders, capacity/queue waiting and cancellation. It is independent of a particular battlefield. Actual unit roles, costs, unlocks, recruitment state, wave state and objective values must be read from the current runtime, never copied as fixed rules from an illustrative drawing.

Drag start and preview remain presentation only; release uses the existing revalidation/submission behavior. Deliberate card clicks and R retain the existing commands under the latest direct human choice. Cancellation clears only an unsubmitted drag; it does not imply cancelling accepted orders or changing recruitment rules.

Common HUD source envelopes and the first native UI pass can be checked independently, but their existence cannot establish camera registration, route visibility or HUD safety over the replacement map. The old 1440×900 / 1280×800 map projections and overlap findings are obsolete. Both resolutions still require actual Korean, Japanese and furigana inspection after the new map is integrated.

No late unlock demonstration, special hunter, boat, convoy, evacuation, new combat/recruitment/save rule or cutscene preparation is introduced by this retained research. No remaster-v1 artwork or pre-clarification Canva experiment is approved or activated as the first map.

Design completed, implementation completed, actual screen confirmed and natural combat confirmed must be reported separately. The replacement historical/spatial design, final map art, implemented terrain and natural-wave contact verification remain unfinished.
